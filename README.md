# Битва Героев — пошаговая 2D-игра на Unity 6

Простая пошаговая тактическая игра в духе сражений Heroes of Might and Magic III:
армии двух героев на гексагональном поле, инициатива, ответные удары, стрелки,
магия героя и ИИ противника.

Проект: `D:\UnitP\f1\HeroesBattle2D`
Версия Unity: **6000.4.7f1** (Unity 6.4), Built-in Render Pipeline, 2D.
Вся графика (гексы, жетоны, иконки, панели, фон) генерируется кодом — внешних ассетов нет.

---

## Как запустить

1. Unity Hub → **Add** → **Add project from disk** → выбрать `D:\UnitP\f1\HeroesBattle2D`.
2. Открыть сцену `Assets/Scenes/Battle.unity` (она уже добавлена в Build Settings).
3. Нажать **Play**.

Готовый билд: `Builds\HeroesBattle.exe` (Windows x64, окно 1600×900).

## Управление

| Действие | Как |
|---|---|
| Выбрать гекс для движения | ЛКМ по синему гексу |
| Атаковать | ЛКМ по врагу (красная рамка) |
| Выстрел стрелком | ЛКМ по любому врагу, если рядом нет врагов |
| Ждать | `Space` или кнопка «Ждать» |
| Защита (+30% защиты) | `D` или кнопка «Защита» |
| Пропустить ход | `P` или кнопка «Пропуск» |
| Заклинание | `1` / `2` / `3` или кнопка, затем клик по цели |
| Отменить заклинание / выбор | ПКМ или `Esc` |
| Подсказка по отряду | навести курсор на жетон |
| Включить/выключить звук | `M` или кнопка «Звук» (меню и HUD) |

## Правила боя

- Поле **10×8 гексов**, у каждого героя до **4 отрядов**.
- Раунд: отряды ходят **по инициативе** (скорости). Очередь видна в верхней панели.
- **Движение** — до скорости гексов за ход; препятствия (камни) блокируют проход.
  Летающие отряды (грифоны, ангелы) игнорируют препятствия.
- **Ближний бой**: подойди и ударь. Защитник отвечает один раз за раунд.
- **Стрелки**: стреляют по любой цели, пока есть патроны; вплотную стрелять нельзя.
- **Защита**: +30% защиты до следующего хода отряда.
- **Урон**: `бросок 1..N × количество × модификатор атаки/защиты` (формула HoMM3,
  ±5% за каждую единицу разницы). Убитые считаются по общему HP отряда.
- Победа — когда уничтожена вся армия противника.

## Звук и музыка

Все звуки синтезируются в коде (`Assets/Scripts/Audio/SfxSynth.cs`) — аудиофайлов в проекте нет:

- клики интерфейса, движение, удар в ближнем бою, выстрел из лука;
- «Стрела магии», баффы, смерть отряда, фанфары победы/поражения, звук ошибки;
- фоновая эмбиент-музыка: 24-секундный луп (аккорды Dm–Bb–F–C + щипковая мелодия),
  генерируется при старте.

Менеджер звука — `Assets/Scripts/Audio/Sfx.cs`: пул из 10 источников, случайный питч,
отключение через `M` или кнопку «Звук» (состояние запоминается в `PlayerPrefs`).
Проверка синтеза: `HeroesBattle → Test → Validate Audio` — 11 SFX и музыка проходят
контроль длины, пика, RMS и отсутствия NaN.

## Магия героя

Одно заклинание за раунд, ограничено маной:

| # | Заклинание | Мана | Эффект |
|---|---|---|---|
| 1 | Стрела магии | 5 | 10 + 10×сила магии урона, игнорирует защиту |
| 2 | Благословение | 3 | отряд всегда наносит максимальный урон |
| 3 | Ускорение | 3 | +3 скорости до конца боя |

Герои: **Сэр Кристиан** (атака +2, сила магии 1, 9 маны) и **Аделаида**
(сила магии 3, 15 маны). ИИ-герой тоже колдует.

## Отряды

Замок (игрок): Копейщики (60), Лучники (120), Грифоны (220), Мечники (320),
Рыцари (1000), Ангелы (3000).

Орда (противник): Гоблины (40), Скелеты (55), Орки-лучники (150), Волки (220),
Огры (520), Личи (1600).

Бюджет армии игрока — **6000 золота**, до 4 разных отрядов. Противник получает
армию на 100% / 110% / 130% стоимости армии игрока (Легко / Норма / Сложно).

```
  Scripts/
    Core/

      Spells.cs                — заклинания и герои
      Army.cs                  — бюджет, генерация армий, сложность
      BattleTypes.cs           — отряд, урон, действия
      BattleState.cs           — все правила боя (без графики)

    View/
      ProceduralArt.cs         — генерация всех спрайтов
      UiKit.cs                 — хелперы uGUI
      BattleView.cs            — поле, жетоны, анимации
      BattleHUD.cs             — интерфейс боя, журнал, результаты
      MainMenuUI.cs            — главное меню
      ArmySelectUI.cs          — сбор армии
    Audio/
      SfxSynth.cs              — синтез SFX и музыки (PCM, 44.1 кГц)
      Sfx.cs                   — пул источников, музыка, mute
    Game/
      GameRoot.cs              — состояния экранов, запуск боя
      BattleController.cs      — ввод, очередь ходов, связка логики и вида
  Editor/
    ProjectSetup.cs            — создание сцены, настройки, сборка .exe
    BattleSelfTest.cs          — автотест 300 боёв

```

## Сборка и проверки

Меню Unity: `HeroesBattle → Setup Project`, `HeroesBattle → Build Windows`,
`HeroesBattle → Test → Simulate 300 battles`.

Из командной строки:

```powershell
$unity = "D:\Program Files\Unity2021\6000.4.7f1\Editor\Unity.exe"

# настройка сцены и проекта
& $unity -batchmode -quit -projectPath "D:\UnitP\f1\HeroesBattle2D" `
  -executeMethod HeroesBattle.EditorTools.ProjectSetup.Configure -logFile configure.log

# автотест правил (300 боёв ИИ против ИИ)
& $unity -batchmode -quit -projectPath "D:\UnitP\f1\HeroesBattle2D" `
  -executeMethod HeroesBattle.EditorTools.BattleSelfTest.RunBatch -logFile test.log

# проверка звука (11 SFX + музыка)
& $unity -batchmode -quit -projectPath "D:\UnitP\f1\HeroesBattle2D" `
  -executeMethod HeroesBattle.EditorTools.AudioSelfTest.RunBatch -logFile audio.log

# сборка Windows-билда
& $unity -batchmode -quit -projectPath "D:\UnitP\f1\HeroesBattle2D" `
  -executeMethod HeroesBattle.EditorTools.ProjectSetup.BuildWindows -logFile build.log
```

Результат последней проверки: **300 боёв, 0 ошибок**, средняя длительность 6 раундов,
максимум 12; побед «игрока» в автосимуляции: легко 87%, норма 76%, сложно 29%
(живой игрок обычно сильнее ИИ). Все 11 звуков и музыка проходят тест `Validate Audio`
(длина, пик, RMS, отсутствие NaN), полный автобой с анимациями и звуком доходит до
экрана результата без исключений.

Скриншоты для проверки рендера лежат в `Builds\Screenshots\`
(меню, сбор армии, бой, экран результата). Их можно пересоздать запуском
`HeroesBattle.exe -shotmenu`, `-shotselect`, `-shotbattle`, `-shotresult`.

## Диагностический автобой

`HeroesBattle.exe -shotresult` запускает случайный бой, играет обе стороны ИИ
(ускоренно) и сохраняет экран результата — удобно для проверки, что весь цикл
боя, анимаций и UI работает без исключений.
